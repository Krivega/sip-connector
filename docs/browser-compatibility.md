# Совместимость браузеров

## Минимальные версии браузеров

Для исходящих звонков SDK использует `AbortSignal.prototype.throwIfAborted()`, чтобы проверить, отменил ли пользователь звонок до отправки SIP-запроса `INVITE`. Минимальные версии браузеров учитывают встроенную поддержку этого метода. [Данные о совместимости MDN](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal/throwIfAborted#browser_compatibility)

| Браузер     | Версия | Уровень поддержки | Особенности                    |
| ----------- | ------ | ----------------- | ------------------------------ |
| **Chrome**  | 100+   | Полная поддержка  | Все возможности WebRTC         |
| **Firefox** | 97+    | Полная поддержка  | Все возможности WebRTC         |
| **Safari**  | 15.4+  | Базовая поддержка | Ограниченная поддержка кодеков |
| **Edge**    | 100+   | Полная поддержка  | Chromium-based                 |

## Проверка возможностей

```typescript
// Проверка поддержки WebRTC
if (!navigator.mediaDevices?.getUserMedia) {
  throw new Error('WebRTC не поддерживается');
}

// Проверка поддержки презентаций
if (!navigator.mediaDevices?.getDisplayMedia) {
  console.warn('Screen sharing не поддерживается');
}

// Проверка поддержки ICE restart
if (!RTCPeerConnection.prototype.restartIce) {
  console.warn('ICE restart не поддерживается в этом браузере');
}
```

## Один вариант H.264 в Firefox 104–137

Чтобы предотвратить зависание входящего видео при запуске демонстрации экрана,
в Firefox 104–137 коннектор автоматически оставляет в каждой видеосекции
исходящего SDP один вариант H.264 с `packetization-mode=1` и связанный RTX (`apt`).
Если в секции нет подходящего H.264, список форматов сохраняется.
